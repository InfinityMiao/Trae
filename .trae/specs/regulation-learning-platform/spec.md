# 制度学习与问题反馈平台 - 产品需求文档

## Overview
- **Summary**: 制度学习与问题反馈平台是一个面向企业内部员工的学习系统，提供制度内容学习、在线考试和问题反馈功能，同时配备完整的后台管理系统。
- **Purpose**: 解决企业内部制度学习、考试和反馈的需求，提高员工对制度的理解和执行能力，同时为管理层提供有效的管理工具。
- **Target Users**: 企业员工和管理层

## Goals
- 提供便捷的制度学习平台，支持PDF文档展示，展示页面不可以下载与复制
- 实现在线考试测试功能，自动评分
- 建立问题反馈机制，及时处理员工疑问
- 搭建完整的后台管理系统，方便管理员进行内容和用户管理
- 确保系统响应式设计，适配移动设备

## Non-Goals (Out of Scope)
- 不支持视频或音频学习内容
- 不包含复杂的数据分析功能
- 不提供外部API接口
- 不支持多语言版本
- 不支持考试计时功能
- 不支持发布/结束考试状态管理
- 不支持导出考试记录

## Background & Context
- 企业内部制度更新频繁，需要一个统一的平台进行管理和学习
- 传统的学习方式效率低下，缺乏有效的考试和反馈机制
- 移动办公趋势明显，需要支持移动端访问
- 企业内部存在部门和岗位差异，需要基于权限的内容控制

## Functional Requirements
- **FR-1**: 用户认证与权限管理 - 用户登录、登出、个人信息管理、密码修改，基于部门/岗位的权限控制
- **FR-2**: 部门与岗位管理 - 部门树状管理、岗位管理，岗位与部门关联
- **FR-3**: 用户管理 - 管理员对用户的增删改查、密码重置、状态管理
- **FR-4**: 制度学习内容管理 - 制度上传（PDF）、制度发布/下架、权限设置、学习统计
- **FR-5**: 在线考试系统 - 考试创建、试题管理、权限设置、自动评分、成绩统计
- **FR-6**: 问题反馈系统 - 员工提交反馈、管理员查看回复、状态管理

## Non-Functional Requirements
- **NFR-1**: 响应式设计，适配不同屏幕尺寸（移动端、平板、桌面端）
- **NFR-2**: 页面加载速度快，用户体验良好
- **NFR-3**: 系统稳定性高，运行可靠
- **NFR-4**: 用户数据安全，权限控制有效

## Constraints
- **Technical**: 前端使用 Vue 3 + Element Plus，后端使用 Express + MySQL
- **Business**: 系统需在规定时间内完成开发和部署
- **Dependencies**: 无外部系统依赖

## Assumptions
- 企业内部网络环境稳定
- 员工具备基本的计算机操作能力
- 管理员具备一定的技术基础

## Acceptance Criteria

### AC-1: 用户登录
- **Given**: 用户已注册且账户状态正常
- **When**: 用户输入正确的用户名和密码进行登录
- **Then**: 系统验证通过，跳转到首页，生成JWT Token
- **Verification**: programmatic

### AC-2: PDF文档防下载防复制
- **Given**: 用户打开制度详情页查看PDF文档
- **When**: 用户尝试右键菜单、选择文本、按Ctrl+C或Ctrl+P
- **Then**: 这些操作都被禁用，无法下载或复制PDF内容
- **Verification**: human-judgment

### AC-3: 制度权限控制
- **Given**: 制度设置了可见部门和岗位
- **When**: 不同部门/岗位的用户访问制度列表
- **Then**: 用户只能看到有权限查看的制度
- **Verification**: programmatic

### AC-4: 在线考试自动评分
- **Given**: 用户完成考试并提交答案
- **When**: 系统接收到提交的答案
- **Then**: 系统自动比对正确答案，计算总分，判断是否及格
- **Verification**: programmatic

### AC-5: 问题反馈处理
- **Given**: 员工提交了问题反馈
- **When**: 管理员查看并回复反馈
- **Then**: 反馈状态更新为已解决，员工可以查看回复
- **Verification**: programmatic

### AC-6: 响应式设计
- **Given**: 用户使用不同设备（手机、平板、电脑）访问系统
- **When**: 用户浏览各个页面
- **Then**: 页面布局自适应，显示效果良好
- **Verification**: human-judgment

### AC-7: 部门岗位关联
- **Given**: 创建岗位时
- **When**: 选择所属部门
- **Then**: 岗位与部门建立关联关系
- **Verification**: programmatic

### AC-8: 考试记录查询
- **Given**: 用户参加过多次考试
- **When**: 用户查看历史考试记录
- **Then**: 显示所有历史考试的得分和是否及格信息
- **Verification**: programmatic
