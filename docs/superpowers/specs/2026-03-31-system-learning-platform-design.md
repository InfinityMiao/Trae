# 制度学习与问题反馈平台设计文档

## 1. 项目概述

制度学习与问题反馈平台是一个面向企业内部员工的学习系统，提供制度内容学习、在线考核测试和问题反馈功能，同时配备完整的后台管理系统。

### 1.1 目标用户
- 企业员工：学习制度内容、参加考核、反馈问题
- 管理层：管理用户、内容、考核和反馈

### 1.2 核心功能
- 用户认证与权限管理
- 制度学习内容管理（PDF文档展示，禁止下载与复制）
- 在线考核测试系统（自动评分）
- 问题反馈系统
- 后台管理系统

## 2. 技术架构

### 2.1 技术栈
- **前端**：Vue.js + Vite + Vue Router + Pinia
- **后端**：Node.js + Express + Sequelize ORM
- **数据库**：MySQL
- **部署**：前端静态部署，后端服务部署

## 3. 系统设计

### 3.1 数据库设计

#### 用户表 (users)
- `id` (主键)
- `username` (用户名)
- `password` (密码哈希)
- `name` (姓名)
- `email` (邮箱)
- `phone` (电话)
- `department_id` (部门ID)
- `position_id` (岗位ID)
- `role` (角色: admin/employee)
- `created_at` (创建时间)
- `updated_at` (更新时间)

#### 部门表 (departments)
- `id` (主键)
- `name` (部门名称)
- `created_at` (创建时间)
- `updated_at` (更新时间)

#### 岗位表 (positions)
- `id` (主键)
- `name` (岗位名称)
- `department_id` (部门ID)
- `created_at` (创建时间)
- `updated_at` (更新时间)

#### 制度表 (policies)
- `id` (主键)
- `title` (标题)
- `description` (描述)
- `file_path` (文件路径)
- `created_by` (创建人)
- `created_at` (创建时间)
- `updated_at` (更新时间)

#### 考核表 (exams)
- `id` (主键)
- `title` (标题)
- `description` (描述)
- `policy_id` (关联制度ID)
- `created_by` (创建人)
- `created_at` (创建时间)
- `updated_at` (更新时间)

#### 考题表 (exam_questions)
- `id` (主键)
- `exam_id` (关联考核ID)
- `question` (问题)
- `option_a` (选项A)
- `option_b` (选项B)
- `option_c` (选项C)
- `option_d` (选项D)
- `correct_answer` (正确答案)
- `created_at` (创建时间)
- `updated_at` (更新时间)

#### 答题记录表 (exam_records)
- `id` (主键)
- `user_id` (用户ID)
- `exam_id` (考核ID)
- `score` (得分)
- `answers` (答案JSON)
- `created_at` (创建时间)

#### 问题反馈表 (feedback)
- `id` (主键)
- `user_id` (用户ID)
- `content` (反馈内容)
- `status` (状态: pending/processed)
- `response` (回复内容)
- `created_at` (创建时间)
- `updated_at` (更新时间)

### 3.2 前端设计

#### 页面结构
- **登录页**：用户登录界面
- **首页**：制度学习、考核、反馈入口
- **制度学习页**：PDF文档展示（禁止下载与复制）
- **考核测试页**：在线考试界面
- **反馈页**：问题提交与查看界面
- **后台管理**：用户、部门、岗位、制度、考核、反馈管理

#### 响应式设计
- 桌面端：完整功能展示
- 移动端：适配小屏幕，保持核心功能

### 3.3 后端设计

#### API接口
- **认证接口**：登录、注册、退出
- **用户管理**：用户CRUD操作
- **部门管理**：部门CRUD操作
- **岗位管理**：岗位CRUD操作
- **制度管理**：制度CRUD操作、文件上传
- **考核管理**：考核CRUD操作、题目管理
- **反馈管理**：反馈CRUD操作、状态更新

#### 中间件
- **认证中间件**：JWT令牌验证
- **权限中间件**：基于角色的权限控制
- **错误处理中间件**：统一错误处理
